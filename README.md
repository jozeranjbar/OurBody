# بدن ما (OurBody)

اطلس سه‌بعدی تعاملی بدن انسان به زبان فارسی، با نام انگلیسی ساختارها در کنار نام فارسی.
این پروژه نسخه‌ی فارسی‌شده‌ی [Human Atlas](https://github.com/ashemag/human-atlas) (ساخته‌ی ashemag، لایسنس MIT) است.

## امکانات
- چرخاندن، بزرگ‌نمایی و انتخاب هر قطعه با لمس
- ۲۲۳۴ قطعه‌ی مدل‌شده و ۱۵ دستگاه بدن (اسکلت، عضلات، سرخرگ‌ها، سیاهرگ‌ها، اعصاب و ...)
- جستجوی ۳۴۳۲ ساختار به فارسی یا انگلیسی
- جداسازی عضو و نوار «جداکردن قطعات»
- توضیح فارسی برای حدود ۵۷ عضو و استخوان مهم، و توضیح کلی دستگاه برای بقیه

## ساخت APK (بدون نصب Android Studio)
1. همه‌ی فایل‌های پروژه را در ریپوی گیت‌هاب قرار بده (شاخه‌ی `main`).
2. در گیت‌هاب برو به تب **Actions** و گردش‌کار **Build Android APK** را اجرا کن (Run workflow)؛ با هر Push هم خودکار اجرا می‌شود.
3. بعد از پایان (چند دقیقه)، فایل `OurBody-debug-apk` را از بخش Artifacts همان اجرا دانلود کن، از حالت ZIP دربیاور و `app-debug.apk` را روی گوشی نصب کن.

## ساخت محلی
```sh
npm ci
npm run dev        # http://localhost:3016
npm run build      # خروجی در dist/
npm install @capacitor/core @capacitor/android && npm install -D @capacitor/cli
npx cap add android
npm run android:sync
npx cap open android   # در Android Studio: Build > Build APK
```
نیاز به Node.js نسخه‌ی ۲۲.۱۳ یا بالاتر و JDK 21 دارد.

## فایل‌های ترجمه
- `app/fa.json`: ترجمه‌ی فارسی همه‌ی نام‌های آناتومی (کلید: نام انگلیسی). تولید خودکار است و ممکن است اشتباه داشته باشد؛ هر ورودی را می‌توانی مستقیم اصلاح کنی.
- `app/anatomy.ts`: نام و توضیح دستگاه‌ها و توضیح عضوهای مهم.
- `app/page.tsx`: متن‌های رابط کاربری.
